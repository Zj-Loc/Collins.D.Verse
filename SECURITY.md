# Security Policy

## Supported Versions
This repository is actively maintained on the latest version available.

| Version | Supported |
| ------- | --------- |
| Latest  | ✅ Yes     |
| Older   | ❌ No      |

## Reporting a Vulnerability
If you discover a bug, vulnerability, or security-related issue in this universe, please report it through GitHub by opening an issue.

Please include:
- A clear description of the issue
- Steps to reproduce the problem
- Screenshots or code snippets if possible
- Suggested fix (optional)

The issue will be reviewed and resolved as soon as possible.

Thank you for helping improve this universe.
